MÓDULO 01

Computação em Nuvem & Redes

💡 O que é Nuvem?

Nuvem nada mais é do que utilizar o computador de outra empresa (ligado 24/7 num data center seguro) acessando via internet, para que sua aplicação fique no ar para qualquer pessoa no mundo.

MÓDULO 02

Lógica de Programação (Python & JS)

💡 Python vs JavaScript

Python funciona como uma receita de bolo em texto limpo (ótimo para regras, IA e automação). JavaScript é o motor da web que faz sites ficarem vivos e interativos no navegador.

MÓDULO 03

Git & Versionamento

💡 O que é Git?

O Git é o sistema de "Save Game" e a máquina do tempo do seu código. Permite guardar checkpoints (commits) e criar linhas do tempo paralelas (branches) para testar sem estragar o projeto.

Labs & Trilhas Interativas

MÓDULO 04

APIs & MCP (Conexões e IA)

💡 API (O Garçom) e MCP (O Plug Universal)

Uma API é o garçom que leva seu pedido até o servidor/cozinha e traz os dados. O MCP (Model Context Protocol) é o adaptador universal que permite que IAs como o Claude se conectem com segurança a essas APIs e dados.

Labs & Trilhas Interativas

Boas Práticas & Segurança (Security by Design)

Sem Senhas no Código

Nunca coloque senhas, chaves de API ou tokens direto no seu arquivo de código (*hardcoded*). Use sempre variáveis de ambiente (`.env`).

Sem Caixa-Preta

Se o Claude gerou um bloco de código, você precisa ser capaz de explicar o que cada linha faz. Se não souber, pergunte à IA antes de salvar.

Cuidado com o Terminal

Antes de rodar um comando que você não conhece no terminal (especialmente `rm`, `git reset --hard`), entenda o que ele altera e como reverter.
